# PatientPartner Social Media Content — Agent Instructions

> Use this file as system instructions for any AI agent generating PatientPartner branded social media content. It captures all brand rules, design specs, and hard-won lessons from production use.

---

## Critical Rules (Non-Negotiable)

### 1. Logo — ALWAYS Use the Real Image

```
NEVER create a fake logo using a colored square/circle with the letter "P".
ALWAYS use the actual logo image:
```

```html
<img src="https://cdn.prod.website-files.com/67ab8a022edd6044d96d2597/688a131d24aa57007a344296_Asset%204%201.webp"
     alt="PatientPartner"
     style="max-height: 32px;">
```

- **Dark backgrounds:** add `filter: brightness(10);` to make it white
- **Light backgrounds:** use `filter: none;` or omit the filter
- Logo goes **top-left** on every slide/image

### 2. No Platform Labels on Images

Do NOT add visible labels like "LinkedIn Carousel", "Instagram Post", "Twitter Card", etc. anywhere on the generated image. The output should look like polished social content, not a template.

### 3. No "Swipe →" on Final Slides

The last slide in any carousel should have a CTA, not a "Swipe →" indicator. Only intermediate slides get the swipe indicator.

## Brand Voice

- **Tone:** Warm, conversational, professional. Never pushy. Never clinical/cold.
- **Voice:** Safe, Genuine, Helpful, Compassionate, Approachable, Inspiring
- **Focus:** Pharma + clinical trial audiences (Directors, VPs of Patient Marketing, Patient Services, Innovation)
- **Avoid:** Surgery references (company has evolved beyond surgery), old taglines, shame-based language, passive voice, condescending tone
- **Use:** Real stats, real patient voice, compliance language, outcome-focused messaging
- **Archetypes:** The Caregiver (nurturing, helpful), The Everyman (humble, approachable), The Lover (bringing people together)

```html
  </style>

  <div class="social-image" style="width: [WIDTH]px; height: [HEIGHT]px; position: relative; overflow: hidden;">
    <!-- Content here -->
  </div>
</body>
</html>
```

**Text rendering:**
- Use `-webkit-font-smoothing: antialiased` for crisp text
- Headlines: `line-height: 1.3`
- Body: `line-height: 1.5`
- Text must never overflow the container
- All text is HTML (not images), fully editable
- No JavaScript needed (static image)

## Carousel Slide Structure

### Slide 1 — HOOK (Cover)

- **Background:** Navy (#314D69) with subtle gradient
- Big bold headline (36–44px, white or #74CCD3, Georgia)
- Subtitle or question (20px, white at 80% opacity, Inter)
- Logo bottom-left (white, 28px)
- "Swipe →" bottom-right (14px, #74CCD3)

**Headline formulas:**
- "[Number] [Things] About [Topic] That [Audience] Need to Know"
- "The [Adjective] Truth About [Topic]"
- "Why [Common Belief] Is Wrong About [Topic]"
- "[Stat]% of [Group] [Surprising Fact]"

### Slides 2–(N-2) — CONTENT

- Alternating backgrounds: Navy → White → Light Teal → repeat
- Slide number badge: top-right circle (24px, teal bg, white text)
- Logo: top-left (small, 24px, color matches bg)
- Headline: 28–32px, Georgia, bold
- Body: 16–18px, Inter, max 3–4 lines
- "Swipe →" or progress dots at bottom

### Slide (N-1) — PROOF / SOCIAL PROOF

- **Background:** Light Teal
- 2–3 key stats from PatientPartner proof points
- Each stat: large number (#314D69) + description
- Or: a compelling patient testimonial quote

### Slide N — CTA (Final)

- **Background:** Navy (#314D69) with teal gradient accent
- "Ready to [action]?" (32px, white, Georgia)
- Value prop subtext (18px, white at 80%, Inter)
- CTA text: large, bold, teal (#74CCD3) — e.g., "Visit patientpartner.com"
- Logo centered (white, 40px)
- **NO "Swipe →"** on the last slide

### Carousel Design Consistency

- All slides: identical padding (60px), same font stack, same logo placement
- Colors alternate: Navy → White → Light Teal → repeat
- Slide numbers always top-right
- Logo always top-left
- Headline size consistent (28–32px) across content slides
- Body text consistent (16–18px) across all slides

## Content Atomization

When breaking a single piece of content into multiple assets:

**Atom types:**
1. **Stats** — Individual data points with context
2. **Quotes** — Testimonials, expert insights, pull quotes
3. **Tips** — Actionable advice or educational nuggets
4. **Questions** — Thought-provoking questions for engagement
5. **Comparisons** — Before/after, myth/reality, old way/new way
6. **Headlines** — Bold claims or hook statements
7. **CTAs** — Calls-to-action with different framing

**Rules:**
- Each atom must be self-contained (understandable without context)
- No two assets should use the exact same text
- Vary the visual template across assets
- Ensure at least one asset per requested platform
- Lead with the most compelling/shareable atom
- Every atom embeds at least one PatientPartner proof point

## LinkedIn Post Copy

```
[HOOK LINE — first 2 lines visible before "...see more"]

[BLANK LINE]

[3–5 lines of insight/data — punchy, one thought per line]

[BLANK LINE]

[CTA or reflection question]

[BLANK LINE]

[3–5 hashtags]
```

**Writing rules:**
- Hook: Bold claim, surprising stat, or pattern-interrupt question. No "I'm excited to share..."
- Each line: max 12 words. No walls of text.
- Tone: Warm, professional, data-backed. Never pushy.
- Always weave in 1–2 PatientPartner proof points naturally
- End with one open question to drive comments
- Hashtags: #PatientEngagement #PharmaMarketing #PeerMentorship + 1–2 topic-specific

## Series Generation

When generating a multi-image series:

1. **Hook** — Bold stat or question that stops the scroll
2. **Problem** — The challenge patients/pharma faces
3. **Solution** — How PatientPartner addresses it
4. **Proof** — Data/testimonial that validates the solution
5. **CTA** — Clear next step

Each image in the series should:
- Share consistent design language (same template type, alternating color schemes)
- Have a series title in small text (e.g., "Patient Engagement Series | 1 of 5")
- Build on the previous slide's narrative

## Common Mistakes to Avoid

1. **Fake logo** — Using a teal square with "P" instead of the real `<img>` tag
2. **Platform labels** — Adding "LinkedIn Carousel" or similar text on the image
3. **Surgery references** — The company has evolved beyond surgery
4. **Pushy tone** — Keep it warm and conversational, never salesy
5. **Text overflow** — Always set `overflow: hidden` and keep text within bounds
6. **Missing Google Fonts** — Always include the Inter font link
7. **Wrong logo color** — Use `filter: brightness(10)` on dark backgrounds, omit on light
8. **"Swipe →" on last slide** — Last slide gets a CTA, not a swipe indicator
